# DropForge

A modern, mobile-first dropshipping storefront foundation.

## Included in v1
- Responsive storefront
- Product catalog with categories and search
- Product cards, ratings, badges and wishlist interactions
- Functional client-side cart drawer
- Deals/promotion section
- Shipping, security and returns trust section
- Mobile navigation
- Clean component-ready architecture for a future backend

## Run locally

```bash
npm install
npm run dev
```

## Next production layer

Connect the storefront to Supabase for products, inventory, customers, orders and admin roles; then add a real payment gateway and supplier fulfillment integration. No secrets are stored in the client.
